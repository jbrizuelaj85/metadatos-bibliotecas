❓ Cómo usar la aplicación

📠

Buscar por ISBN

Ingresa el ISBN-10 o ISBN-13 del libro. Es el método más preciso para obtener metadatos exactos.

Ej: 9788497592208
📰

Buscar por Título

Escribe el título completo o parcial del libro. Puedes incluir el autor para mayor precisión.

Ej: Cien años de soledad
👤

Buscar por Autor

Ingresa el nombre del autor para ver todas sus obras disponibles en las fuentes consultadas.

Ej: Gabriel García Márquez
🔗

Buscar por DOI

Para artículos académicos, ingresa el DOI (Digital Object Identifier) para obtener metadatos precisos.

Ej: 10.1038/s41586-021-03819-2

⬇️ Formatos de exportación

Los resultados pueden exportarse en los siguientes formatos:

📄 BibTeX📃 RIS📊 CSV📋 JSON

🗄️ Fuentes de datos

La aplicación consulta automáticamente múltiples fuentes:

  • 🔎 Google Books API - Millones de libros con metadatos completos
  • 📚 Open Library - Catálogo abierto de Internet Archive
  • 🎓 CrossRef - Metadatos de literatura académica y DOI
