❓ Como usar la aplicacion

🖻

Buscar por ISBN

Ingresa el ISBN-10 o ISBN-13 del libro. Es el metodo mas preciso para obtener metadatos exactos.

Ej: 9788497592208
📰

Buscar por Titulo

Escribe el titulo completo o parcial del libro. Puedes incluir el autor para mayor precision.

Ej: Cien anos de soledad
👤

Buscar por Autor

Ingresa el nombre del autor para ver todas sus obras disponibles en las fuentes consultadas.

Ej: Gabriel Garcia Marquez
🔗

Buscar por DOI

Para articulos academicos, ingresa el DOI (Digital Object Identifier) para obtener metadatos precisos.

Ej: 10.1038/s41586-021-03819-2

⬇ Formatos de exportacion

Los resultados pueden exportarse en los siguientes formatos:

📄 BibTeX 📃 RIS 📊 CSV 📋 JSON

🗃 Fuentes de datos

  • 🔎 Google Books API - Millones de libros con metadatos completos
  • 📚 Open Library - Catalogo abierto de Internet Archive
  • 🎓 CrossRef - Metadatos de literatura academica y DOI
